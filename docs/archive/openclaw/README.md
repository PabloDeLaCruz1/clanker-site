# OpenClaw historical archive

This directory preserves the repository's former OpenClaw operating context for provenance. Nothing here is current runtime configuration.

- `AGENTS.md` is the original agent-home instruction file.
- `legacy/` contains the former identity, memory, setup notes, Moltbook queue, machine-specific automation scripts, and uploader utility.

Do not restore these files to the repository root without an explicit product and security review. They may contain stale machine paths, operating assumptions, or personal context.
